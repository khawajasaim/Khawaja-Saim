UPDATE YOUR EXISTING REPOSITORY
1. Extract this ZIP on your computer. GitHub does not extract ZIP files for you.
2. Open https://github.com/khawajasaim/Khawaja-Saim
3. Choose Add file > Upload files in the repository root.
4. Upload index.html, meta-mesh.js, meta-scroll.js, robots.txt and sitemap.xml.
   These files must be side by side in the folder used by GitHub Pages.
5. Commit changes to the branch currently used by GitHub Pages.
6. Wait for the Pages deployment to finish, then open:
   https://khawajasaim.github.io/Khawaja-Saim/
7. Refresh the page with Ctrl + Shift + R if the previous version appears.
